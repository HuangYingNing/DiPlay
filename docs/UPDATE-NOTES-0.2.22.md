# DiPlay 0.2.22 更新说明

- 合并原始项目 0.2.16 之后至 0.2.22 的源码更新，基础版本号同步为 `0.2.22`。
- 合入车机热点无线连接、Wi-Fi 音乐时钟、USB 语音录制、有线重连与连接失败诊断等上游修复。
- 合入更新下载校验、输入边界与诊断信息处理等上游安全修复。
- 保留本项目的吉利星愿车机适配、GD 车桥、ADB 诊断、PasteDB 日志上传和黄颖宁 Release 更新通道。
- PasteDB API Key 仍由本地忽略文件或 GitHub Actions Secrets 注入构建；密文与解密密钥不得提交 Git。
- 发布版本继续使用 `v0.2.22-bYYMMDD-nnn` 格式；日志上传时附带源码 commit 号。

上游各项变更及其验证限制见 [原始项目 0.2.22 发布说明](RELEASE-NOTES-0.2.22.md) 和[验证记录](VALIDATION.md)。合并后的完整版本尚未在吉利星愿车机上完成实车验证，不代表已确认所有上游功能均与 Flyme Auto 兼容。
